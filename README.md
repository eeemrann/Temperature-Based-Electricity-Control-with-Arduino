🔌 Temperature-Based Electricity Control with Arduino

This project is a smart home automation system built using Arduino that controls electrical appliances based on ambient temperature. It uses a temperature sensor (like the LM35 or DHT11) to monitor the environment and automatically turns on/off connected devices (e.g., fans, heaters) to maintain a desired temperature range. Ideal for energy efficiency and intelligent temperature regulation in homes or offices.

---

🔧 Features
Real-time temperature monitoring

Automatic control of electrical devices based on threshold temperature

Customizable temperature limits

Simple, low-cost hardware setup

Code written in Arduino IDE (C/C++)

---

🛠️ Hardware Used
Arduino UNO (or compatible board)

Temperature sensor (e.g., LM35 or DHT11)

Relay module

Power source

Electrical load (fan, heater, etc.)

---

📂 How It Works
The sensor reads the current temperature.

If the temperature exceeds a preset limit, the relay is triggered to activate a cooling/heating device.

Once the temperature drops/raises to a safe level, the device is turned off automatically.
